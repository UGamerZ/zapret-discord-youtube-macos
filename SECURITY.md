# Сообщения об уязвимостях / Security reports

Пакетный движок использует права root, PF и BPF. Для уязвимостей в запуске, управляющем сокете, обработке пакетов или восстановлении используйте [приватное сообщение GitHub](https://github.com/UGamerZ/zapret-discord-youtube-macos/security/advisories/new).

Укажите версию приложения и macOS, условия воспроизведения и возможное воздействие. Не публикуйте рабочий эксплойт или личные журналы в открытом Issue до обсуждения с сопровождающим. Срок ответа и исправления не гарантируется.

Обычные сбои подключения и результаты проверки провайдера направляйте в [Issues](https://github.com/UGamerZ/zapret-discord-youtube-macos/issues/new/choose).

## English

Use [GitHub private vulnerability reporting](https://github.com/UGamerZ/zapret-discord-youtube-macos/security/advisories/new) for security flaws. Include the affected app/macOS versions, reproduction and impact. Avoid public exploit details or personal logs before discussing the report with the maintainer. No response-time or fix-time commitment is made. Use Issues for ordinary connectivity bugs.
