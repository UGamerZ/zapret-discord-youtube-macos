## Короткий анонс

**Zapret macOS — графическое приложение с оригинальными стратегиями Flowseal для Mac.**

SwiftUI-интерфейс, 22 профиля, оригинальный пакетный движок bol-van, Game mode, подбор стратегии и диагностика. Готовая универсальная сборка для Apple Silicon и Intel, macOS 13+: компилятор и Python для запуска не нужны.

Транспорт PFLOG/BPF экспериментальный: сборка и автономные тесты проходят, полноценные сетевые испытания ещё не завершены. Нужны отчёты о работе на реальных провайдерах. Для подключения требуются права администратора; обычные VPN-туннели не поддерживаются. Сборка не нотариализована Apple.

Скачать: https://github.com/UGamerZ/zapret-discord-youtube-macos/releases/latest
Исходники и инструкция: https://github.com/UGamerZ/zapret-discord-youtube-macos

## English announcement

**Zapret macOS brings the original Flowseal profiles and bol-van packet engine to a native SwiftUI app.**

22 profiles, Game mode, strategy comparison and packet diagnostics. A universal prebuilt app is available for Apple Silicon and Intel on macOS 13+; no compiler or Python needed to run it.

The PFLOG/BPF transport is experimental. Builds and offline tests pass; full live network validation is still pending. ISP test reports are welcome. Administrator approval is required; ordinary VPN tunnel interfaces are unsupported. The build is ad hoc signed and not Apple-notarized.

Download: https://github.com/UGamerZ/zapret-discord-youtube-macos/releases/latest
Source and documentation: https://github.com/UGamerZ/zapret-discord-youtube-macos
