# История изменений / Changelog

## 0.2.2

- Исправлен фильтр входящих SYN/ACK: вместо несовместимого с Ethernet квалификатора `inbound` используется `pcap_setdirection(PCAP_D_IN)` и переносимый фильтр IPv4/IPv6.
- Добавлены этап, конкретная причина, подробности и код ошибки настройки транспорта, а также действия Copy error и Open log.
- Опубликована готовая универсальная сборка для macOS 13+, Apple Silicon и Intel.
- Основное руководство переведено на русский; добавлены установка без сборки и SHA-256.

0.2.2 публикуется как обычный релиз. Статус PFLOG/BPF-транспорта остаётся экспериментальным; границы проверки описаны в [VALIDATION.md](VALIDATION.md).

## 0.2.1

- Запуск через `nohup` заменён на `fork`/`setsid`/`exec` с подтверждением запуска, PID-файлом и перенаправлением потоков.
- Ранние ошибки запуска возвращаются в интерфейс.

## 0.2.0

- Добавлены оригинальный пакетный движок bol-van и транспорт PFLOG/BPF для macOS.
- Импортированы все 22 оригинальных профиля Flowseal, списки и бинарные шаблоны.
- Добавлены автономные проверки соответствия аргументов и обработки TCP/UDP, TLS/QUIC, IPv4/IPv6.

## 0.1.0

- Ранний прототип интерфейса с адаптацией через SOCKS. Этот транспорт заменён пакетным в версии 0.2.0.
